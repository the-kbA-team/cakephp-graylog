# CakePHP 2 Graylog

The CakePHP 2 package has moved to
[`kba-team/cakephp2-graylog`](https://github.com/the-kbA-team/cakephp2-graylog).

To migrate, replace `kba-team/cakephp-graylog` with `kba-team/cakephp2-graylog`
in your `composer.json` and update your dependencies. The packages must not be
installed together. The new package requires PHP 8.1 or later and retains the
`Graylog` plugin name and configuration.
